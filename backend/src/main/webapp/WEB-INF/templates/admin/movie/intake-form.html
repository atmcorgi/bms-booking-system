Upload Movie CSV

Step 1: Upload
Hướng dẫn:

Upload file CSV chứa thông tin phim từ khách hàng. File CSV cần có các cột:

  • movie_code: Mã phim (unique, không cần prefix theater)
  • title: Tên phim
  • duration: Thời lượng (phút)
  • priority: Độ ưu tiên (0.1-1.0)
  • demand_score: Điểm dự đoán (0.1-1.0)
  • formats: Định dạng (2D|3D|IMAX)
  • languages: Ngôn ngữ (VI|EN|CN)
Lưu ý: Sau khi import, ADMIN cần assign movies cho các theaters thông qua "Assign Movie".
